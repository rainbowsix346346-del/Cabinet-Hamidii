# کابینت حمیدی (React + Vite)

    npm install
    npm run dev      # توسعه
    npm run build    # خروجی نهایی در dist/

ساختار: `config/` تنظیمات، `data/` محتوا، `utils/` توابع کمکی، `hooks/` هوک‌ها،
`components/` اجزای UI، `styles/site.css` استایل، `App.jsx` فقط ترکیب‌کننده.

برای وصل کردن فرم به بک‌اند: `FORM_ENDPOINT` در `src/config/business.js`.
برای شماره تماس: `BUSINESS_CONFIG` در همان فایل.
